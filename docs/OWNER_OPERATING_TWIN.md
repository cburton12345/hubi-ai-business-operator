# Ferocity Owner Operating Twin

Ferocity should behave like a governed operational extension of the owner, not a generic chatbot or an undisclosed impersonator.

The first adaptive layer uses tenant-isolated Ask Ferocity history, explicit durable memories, current workspace evidence, authority rules, and verified action outcomes. It preserves recurring owner wording and predicts likely next commands. Suggestions are evidence-labeled and remain subject to the same approval, spending, messaging, publishing, contract, payment, and account-access controls as manually typed commands.

## Learning contract

- Learn from the owner's commands, corrections, accepted outcomes, and explicit preferences.
- Prefer patterns that led to completed Ferocity responses or verified action receipts.
- Preserve the owner's concise tone when suggesting a command.
- Never learn or reproduce passwords, tokens, payment credentials, private keys, government identifiers, or long financial/account numbers.
- Never convert repeated approval into permanent authority. Authority changes require the existing explicit authority workflow.
- Consequential suggestions are `draft_only`; one tap may submit the command for governed planning, but cannot bypass approval gates.
- Show confidence and why the suggestion appeared. Low-confidence predictions remain optional and cannot auto-run.
- Let the owner forget stored memories and correct an active outcome using existing conversation controls.

## Next layers

1. Capture explicit accept/edit/dismiss feedback for each suggestion.
2. Learn channel-specific voice for text, email, calls, and internal commands without conflating audiences.
3. Rank suggestions from verified business outcomes: collected revenue, completed jobs, response time, margin, reliability, and owner corrections.
4. Add a daily owner queue that can prefill the single most likely next command while keeping send/publish/spend/payment work gated.
5. Extend the same governed identity across Ferocity Connect, voice, email, MarketplacePro, and authorized portfolio integrations.
