# Ferocity Promise Audit

This checklist keeps Ferocity honest before launch, after major feature work, and before public copy changes.

Ferocity should sell the real promise:

- AI helps handle approved repeat work.
- The owner stays in control.
- Provider-gated actions are labeled clearly.
- Missing keys should not crash or create dead ends.
- Public pages should explain value in plain English.
- Internal pages can be deeper, but should still point people to the next useful action.

## Launch Rule

Do not claim customer-visible sending, public publishing, ad spend, voice calls, managed payouts, or external platform posting as live unless the required provider is connected, tested, controlled, logged, and recoverable.

Allowed public claims:

- Ferocity organizes leads, jobs, money, reviews, marketing, reminders, and owner attention.
- Ferocity can prepare drafts, recommendations, follow-ups, tasks, reports, and setup plans.
- Ferocity can automate approved work when the needed account, provider, permissions, and controls are in place.

Avoid public claims:

- Guaranteed revenue, rankings, booked jobs, or growth.
- Fully hands-free business operation with no setup.
- Live video generation, ad posting, SMS, voice answering, website publishing, or payouts when the provider is not connected.
- Anything that sounds like Ferocity replaces human judgment, legal advice, tax advice, or compliance review.

## Critical Questions

These questions are now mirrored in `/app/promise-audit`.

1. Are we promising live functionality or only a future idea?
2. Can a normal owner understand what Ferocity does without reading a wall of features?
3. Can someone start without every key connected?
4. Does AI actually create work, or is it just dashboard decoration?
5. Can Ferocity help get more booked income instead of just reporting problems?
6. Can Ferocity run daily operations for a simple business?
7. Can employees use it without seeing owner-only businesses or unrelated projects?
8. Are payments honest and safe?
9. Can customers tell what is included, gated, or upgrade-only?
10. Is marketing/SEO legitimate instead of generic AI output?
11. Can photos, receipts, videos, and proof become useful business records?
12. Will owners get their life back, or will Ferocity create more chores?
13. Can outside platforms feed into one command center?
14. Are expensive AI features isolated from normal AI work?
15. What should block launch?

## How To Use This

Before deploy:

1. Open `/app/promise-audit`.
2. Open `/app/feature-readiness`.
3. Open `/app/go-live`.
4. Compare `/`, `/features`, `/demo`, `/pricing`, and `/start` against this policy.
5. Run the local verification suite.

If a feature is provider-gated, show the setup path. If a feature is draft-only, say that plainly. If a feature is not ready, do not sell it as ready.
