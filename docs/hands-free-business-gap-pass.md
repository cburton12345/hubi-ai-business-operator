# Hands-Free Business Gap Pass

Ferocity should feel like an AI operator for the business, not a pile of separate tools.

## Goal

Make the logged-in app answer four questions clearly:

1. What is Ferocity already watching?
2. What can Ferocity prepare or automate now?
3. What is blocking deeper automation or posting?
4. What should the owner connect or approve next?

## Product Rules

- Do not claim live posting, live ad spend, live payment collection, or live customer sends unless the provider is connected and live actions are enabled.
- Keep manual tools available.
- Use one operating loop: setup, lead capture, follow-up, jobs, money, proof, publishing, reporting.
- Show gaps in plain English.
- Route each gap to an existing Ferocity page instead of creating duplicate workflows.

## First Implementation

- Add a Business Gap Scan page inside the app.
- Summarize automation readiness by business area.
- Show the difference between:
  - ready now
  - needs review
  - needs connection
  - needs data
- Include website/posting/provider gaps.
- Add a navigation link from the Command Center and Autopilot.
- Keep the public promise aligned: AI can run more of the business only where setup, provider, approval, and plan rules allow it.

## Future Work

- Let AI generate a prioritized setup plan from the gap scan.
- Let users select gaps and apply a setup bundle.
- Add scheduled gap scans to the daily brief.
- Add customer-facing “Ferocity found these gaps” onboarding emails.
- Add per-tier upgrade prompts only where a blocked feature has real value.
