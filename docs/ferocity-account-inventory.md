### Credential Rule

- The public inventory records identities, URLs, IDs, and recovery methods.
- `.private/ferocity-account-vault.md` is the local, Git-ignored credential pointer file.
- The password manager or Windows Credential Manager is the source of truth for actual passwords and recovery codes.
- Never infer that two providers share a password. Never save OTPs; they expire.
- If a password is unknown, write `recovery required` rather than guessing or creating a duplicate account.
